🧩 L'accord sujet-verbe

Le verbe change selon le sujet ! Singulier ou pluriel, il doit s'accorder !

📚 CE1 / CE2⏱️ ~15 min⭐⭐ Moyen🎯 Français — Grammaire

📖 La leçon

① Ugo observe ses amis
🦉🧩 Ugo voit son ami : "Le chat DORT." Puis il voit plusieurs chats : "Les chats DORMENT." Le mot DORT est devenu DORMENT ! Le verbe change selon le sujet. C'est l'accord !
L'accord sujet-verbe : le verbe s'accorde avec son sujet.
Sujet singulier → verbe singulier.
Sujet pluriel → verbe pluriel (souvent avec -ent).
② Exemples d'accord
🔵 Singulier
Le chat dort. ✅
Elle mange. ✅
Le chat dorment. ✗
🔵 Pluriel
Les chats dorment. ✅
Ils mangent. ✅
Les chats dort. ✗

💡 Les verbes en -ent = pluriel (ils, elles, les + nom) !

③ La méthode pour vérifier
🦉1) Trouve le verbe. 2) Trouve le sujet. 3) Pose "Qui + verbe ?" 4) Singulier → pas de -ent. Pluriel → -ent ! 🔍
✨ Exception : NOUS → -ons · VOUS → -ez · TU → -es (pour les verbes en -er)
🦉Regarde le sujet ! Singulier (1 chose) → verbe sans -ent. Pluriel (plusieurs) → verbe avec -ent ! 🔵

📝 Ce qu'il faut retenir

🔵Le verbe s'accorde avec son sujet : singulier → verbe singulier · pluriel → verbe avec -ent.
🔵Exceptions : nous → -ons · vous → -ez · tu → -es.
🔵Méthode : trouve le verbe → trouve le sujet → vérifie l'accord.
💡Erreur fréquente : "Les enfants joue" ❌ → "Les enfants jouent" ✅
