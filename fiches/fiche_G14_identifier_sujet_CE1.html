🔎 Identifier le sujet du verbe

Le sujet = celui qui fait l'action. La question magique : "Qui + verbe ?" !

📚 CE1⏱️ ~15 min⭐⭐ Moyen🎯 Français — Grammaire

📖 La leçon

① La question magique d'Ugo
🦉🔎 Ugo lit : "Le chat mange une souris." Il pose la question : "Qui mange ?" → Le chat ! Le chat = le sujet ! Le sujet dit QUI fait l'action du verbe.
Le chat mange une souris.
Le sujet = celui qui fait l'action du verbe.
Question magique : "Qui + verbe ?" → La réponse = le sujet.
② Sujet = nom ou pronom
Le sujet peut être un nom (seul ou avec des mots autour) ou un pronom (je, tu, il, elle, nous, vous, ils, elles).
Le petit chien dort.
Il dort.

💡 Attention : tout le groupe nominal est le sujet ("le petit chien" et non seulement "chien") !

③ Attention aux mots qui se glissent devant !
🦉Parfois des mots complément se mettent devant : "Dans le jardin, les fleurs poussent." Le sujet = LES FLEURS (pas "le jardin"). Toujours poser : "Qui pousse ?" → Les fleurs ! 🌸
✨ Méthode sûre : 1) Trouve le verbe. 2) Pose "Qui + verbe ?". 3) La réponse = le sujet !
🦉Pose la question "Qui + verbe ?" pour trouver le sujet. Clique sur la bonne réponse ! 🔎

✏️ Exercice 1 — Quel est le sujet ?

Clique sur le groupe qui est le sujet du verbe. (1 pt par question)

🦉Rappel : le sujet peut être un pronom (il, elle, nous…) ou un groupe nominal (le chat, mon ami…). 🔍

✏️ Exercice 2 — Trouve le sujet !

Clique sur le sujet du verbe. (1 pt par question)

🦉Est-ce que le groupe souligné est bien le sujet ? Pose "Qui + verbe ?" pour vérifier ! 🔎

🎯 Exercice 3 — Ce groupe est-il le sujet ?

Lis et réponds Oui ou Non. (1 pt par question)

🦉Phrases plus complexes ! Attention aux mots avant le verbe — ce ne sont pas toujours le sujet. Pose bien la question "Qui ?" 🌟

🎯 Exercice 4 — Sujet ou pas ?

Clique sur le groupe qui est le sujet. (1 pt par question)
