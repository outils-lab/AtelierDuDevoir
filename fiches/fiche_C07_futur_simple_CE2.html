Le futur simple

Pour parler de ce qui va se passer demain ou plus tard,
on utilise le futur simple. C'est facile à former ! 🌟

CE2 Conjugaison 15 min 16 pts

📖 Bloc 1 — À quoi sert le futur simple ?

On utilise le futur simple pour parler d'une action qui va se passer dans le futur.

📅 Demain, je chanterai en classe.
📅 L'année prochaine, nous partirons en vacances.
📅 Tu grandiras encore.
🦉 Ugo : Des indices pour repérer le futur : demain, bientôt, l'année prochaine, dans quelques jours… Ces mots annoncent souvent un futur !

📖 Bloc 2 — La règle : infinitif + terminaisons

Pour former le futur simple, on prend l'infinitif du verbe et on ajoute les terminaisons du futur :

je → -ai tu → -as il/elle → -a nous → -ons vous → -ez ils/elles → -ont
chanter → infinitif garde son -er
JechanteraiNouschanterons
TuchanterasVouschanterez
Il / EllechanteraIls / Elleschanteront
🦉 Ugo : Pour les verbes en -re, on enlève le -e final avant d'ajouter les terminaisons. Exemple : prendre → prendr- → je prendrai.

🔑 Bloc 3 — Futurs irréguliers

Quelques verbes très courants ont un radical irrégulier au futur :

être → ser-   (je serai)
avoir → aur-   (tu auras)
aller → ir-    (il ira)
faire → fer-   (nous ferons)
venir → viendr- (vous viendrez)
pouvoir → pourr- (ils pourront)
💡 Astuce : Même pour les irréguliers, les terminaisons restent toujours les mêmes : -ai, -as, -a, -ons, -ez, -ont.
