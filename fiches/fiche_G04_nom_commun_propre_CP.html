📚 Nom commun et nom propre ✨

Des noms pour TOUS... et des noms pour UN SEUL !

📚 CP / CE1 ⏱️ ~15 min ⭐⭐ Moyen 🎯 Français — Grammaire

📖 La leçon

① Découverte avec Ugo
🦉🌿 Un matin, Ugo survole un village. Dans un jardin, un chien court et joue. Le chien s'appelle Rex. Ugo pense : 'chien, c'est pour TOUS les chiens. Mais Rex... c'est SEULEMENT pour ce chien-là !' C'est la leçon d'aujourd'hui ! 🐕
Le nom commun sert pour TOUS les êtres ou les choses du même type. Il s'écrit sans majuscule.

Exemples : un chien, une fleur, une ville, un livre, une école…

② Le nom propre
Le nom propre est le nom d'UNE seule personne, d'UN seul endroit. Il commence TOUJOURS par une majuscule 🔠.

Exemples : Lucas, Emma, Paris, France, Ugo…

👉 Rex = le nom de CE chien-là. Paris = le nom de CETTE ville-là.

③ L'astuce de mémo
🦉Mon astuce 🔠 : regarde la première lettre ! Majuscule → nom propre ✨. Petite lettre → nom commun 📚 !
