🎨 L'adjectif qualificatif

Le mot qui décrit et donne des informations sur un nom.

📚 CE1 / CE2⏱️ ~15 min⭐⭐ Moyen🎯 Français — Grammaire

📖 La leçon

① Ugo et le portrait mystérieux
🦉🎨 Ugo dessine le portrait de son ami. Il écrit juste : "un chat". Son ami demande : "C'est grand ou petit ? Noir ou gris ?" Ugo ajoute alors : "un grand chat gris". GRAND et GRIS décrivent le chat. Ces mots s'appellent des adjectifs !
L'adjectif qualificatif est un mot qui décrit un nom. Il dit comment est la personne, l'animal ou la chose.
un grand 🎨 chat gris 🎨

🎨 = adjectif · nom = le mot décrit

② Plein de sortes d'adjectifs !
L'adjectif peut dire la couleur, la taille, la forme, ou une qualité.
rouge→ couleur 🔴
grand→ taille 📏
rond→ forme ⭕
doux→ qualité 🌸

Une belle fleur rouge — un petit chat blanc

③ L'adjectif s'accorde avec le nom
🦉Astuce 🔍 : l'adjectif change selon le nom qu'il décrit ! Si le nom est féminin, l'adjectif prend souvent un -e. Au pluriel, il prend souvent un -s !
Masc. sing.un chat gris
Fém. sing.une robe grise
Masc. plur.des chats gris
Fém. plur.des robes grises
🦉L'adjectif décrit un nom. C'est un mot comme "grand", "rouge", "doux"… Clique sur l'adjectif ! 🎨

🦉L'adjectif décrit toujours un nom. Lequel est-ce ? Repense à l'histoire du portrait d'Ugo ! 🖼️

✏️ Exercice 2 — Quel nom est décrit ?

🦉Un adjectif décrit un nom. Un verbe exprime une action. Un nom désigne une chose. Fais la différence ! 🔍

📝 Ce qu'il faut retenir

🎨L'adjectif qualificatif est un mot qui décrit un nom : sa couleur, sa taille, sa forme, sa qualité…
🎨Il se place souvent avant le nom (un grand chat) ou après (une fleur rouge).
🎨L'adjectif s'accorde avec le nom : féminin → souvent +e. Pluriel → souvent +s.
💡Astuce : remplace le nom par "il/elle". Si l'adjectif a encore du sens → c'est bien un adjectif !

G09 — L'adjectif qualificatif

CE1 / CE2 · Français — Grammaire · L'Atelier du Devoir

L'adjectif qualificatif décrit un nom. Il dit comment est la chose : couleur, taille, forme, qualité.
Exemples : un grand chat gris · une belle fleur rouge · un livre lourd
Accord : féminin → +e (gris → grise). Pluriel → +s (grise → grises).
