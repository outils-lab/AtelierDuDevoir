🔍 Identifier le verbe dans la phrase

Le verbe dit ce que fait ou ce qu'est le sujet. C'est lui le chef !

📚 CP / CE1⏱️ ~15 min⭐⭐ Moyen🎯 Français — Grammaire

📖 La leçon

① Ugo repère le verbe !
🦉🔍 Ugo lit : "Le chat dort." Il cherche le verbe. Il pose la question : "Le chat fait quoi ?" → Il DORT. DORT = le verbe ! Le verbe dit ce que fait le sujet.
"Le chat dort."
Le verbe = le mot qui dit ce que fait ou ce qu'est le sujet.
Pour le trouver : pose la question "Qui ou quoi + fait/est... ?"
② Le truc pour trouver le verbe
✨ Le truc d'Ugo : Dis la phrase au passé ou au futur. Le mot qui change = c'est le verbe !
"Le chat DORT." → "Le chat DORMAIT." → "Le chat DORMIRA."
DORT / DORMAIT / DORMIRA → c'est bien le verbe !

→ "Les enfants jouent." → hier : "Les enfants jouaient." ✅

→ "Tu chantes bien." → hier : "Tu chantais bien." ✅

③ Verbe d'action ou verbe d'état ?
🦉Certains verbes disent ce qu'on fait (courir, manger, jouer…). D'autres disent ce qu'on est (être, sembler, paraître…). Les deux sont des verbes ! 🦉
"Il court vite."  ·  "Elle est belle."
🦉Clique sur le mot qui est le verbe ! Pour t'aider : pose la question "Qui fait quoi ?" 🔍

✏️ Exercice 1 — Clique sur le verbe !

Lis la phrase. Clique sur le verbe. (1 pt par question)

🦉Parmi ces trois mots, lequel est le verbe ? Pense à changer la phrase au passé — le verbe change ! 🕐

✏️ Exercice 2 — Quel mot est le verbe ?

Clique sur le verbe parmi les 3 mots. (1 pt par question)

🦉Je te montre un mot souligné dans la phrase. Est-ce que ce mot est le verbe ? Dis OUI ou NON ! 🔎

🎯 Exercice 3 — Ce mot est-il le verbe ?

Lis et réponds Oui ou Non. (1 pt par question)

🦉Phrases un peu plus longues ! Le verbe est toujours là. Pose la question : "Qui + fait quoi ?" 🌟
