5) Comment comprendre un texte : la méthode en 5 étapes

1. Reste positif. Tu n'as pas besoin de comprendre tous les mots.
2. Observe le document : le titre, les images, les paragraphes.
3. Trouve les mots-clés : les mots transparents (ils ressemblent au français), les mots répétés, les petits mots and (et) / but (mais).
4. Cherche des indices : les noms propres (avec une majuscule), les pronoms (he, she…), les dates et les lieux.
5. Améliore-toi : note les mots nouveaux, utilise le dictionnaire.
Avec ton texte sur James Bond :
• mots transparents : author = auteur, famous = célèbre (fameux), agent, films, missions ;
• noms propres : James Bond, Ian Fleming, Daniel Craig ;
• pronom : « he became a spy » → he = Ian Fleming ;
• dates et nombres : 1953, twenty-three films, 007.
Mots à retenir : was = le passé de « is » • still = encore • character = personnage • stunts = cascades • created by = créé par.
