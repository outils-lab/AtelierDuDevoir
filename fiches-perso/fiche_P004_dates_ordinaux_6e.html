En anglais, les jours prennent toujours une MAJUSCULE : Monday (et pas monday).
Astuce : ils finissent tous par -day (= jour). Piège d'orthographe : Wednesday (on ne prononce pas le d : « wènzdéï »).

2) Les nombres ordinaux : la règle

Un nombre ordinal dit le rang : premier, deuxième, troisième… On s'en sert pour dire et écrire une date.

La règle : on ajoute th au nombre : four → fourth (4th), six → sixth (6th), seven → seventh (7th).
Sauf 1, 2 et 3 (et les nombres qui finissent par 1, 2, 3) :
1 → 1st = the first
2 → 2nd = the second
3 → 3rd = the third
→ 21st the twenty-first • 22nd the twenty-second • 23rd the twenty-third • 31st the thirty-first
Attention : 11, 12, 13 suivent la règle normale et prennent th : 11th, 12th, 13th.
Astuce : les 2 lettres après le chiffre sont les 2 dernières lettres du mot : first → 1st, second → 2nd, third → 3rd, fourth → 4th.

3) Les 5 changements d'orthographe

5 five
5th → the fifth (ve → f)
8 eight
8th → the eighth (un seul t + h)
9 nine
9th → the ninth (on enlève le e)
12 twelve
12th → the twelfth (ve → f)
20 twenty
20th → the twentieth (y → ie)
Même chose pour toutes les dizaines : thirty → the thirtieth (30th).
Sur ta fiche, il est écrit « the nigth » : c'est une faute de frappe, il faut écrire ninth (n-i-n-t-h).
