4) Les nombres ordinaux : la règle

Un nombre ordinal dit le rang : premier, deuxième, troisième… On s'en sert pour les dates.

La règle : on ajoute th : four → fourth (4th), six → sixth (6th).
Sauf 1, 2 et 3 (et les nombres qui finissent par 1, 2, 3) :
1 → 1st = the first
2 → 2nd = the second
3 → 3rd = the third
→ 21st • 22nd • 23rd • 31st
Attention : 11, 12, 13 prennent th : 11th, 12th, 13th.
Astuce : les 2 lettres après le chiffre sont les 2 dernières lettres du mot : first → 1st, second → 2nd, third → 3rd, fourth → 4th.
